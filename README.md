Interactive e-commerce sales analysis dashboard developed using Power BI.
The dataset used in this project contains e-commerce sales transactions,it icludes two csv files  the Orders file contatin:
Order id
Order data
Customer name 
state 
city
And Details csv include:
Order id
Amount
Profit
Qunatity
Category
Sub category
Payment mode

The dataset was used for data cleaning, analysis, and visualization in Power BI.
